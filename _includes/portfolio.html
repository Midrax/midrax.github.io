Project Description

A wave-based co-op space ship combat game created for the Alt Ctrl Game Jam. The players control a ship moving through an asteroid field with enemies spawning and attacking them.
The controls were implemented on knobs and buttons with an arduino and later adapted to the keyboard and mouse.
