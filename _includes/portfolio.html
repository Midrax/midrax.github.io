Onirico

Previous Next

Roles

Lead Programmer with 2 Game Designers and 2 Artists

Project Description

This is an academic project, developed for DES502 (Game Design and Development), a module from my MSc in Computer Games Technology. It is a 3rd-person stealth game. In this vertical slice we get the chance to play as a WW1 veteran, who appears to be back in his hometown, Aedinbard. The town seems to be covered by some weird fog, and it's crawling with creepy masked men. The main character is guided towards an ancient church by a voice speaking through old radios scattered around the map.
Aedinbard is a place that seems familiar to our character, but in a way he can't quite understand. The main character would eventually find out that he's been dead for a few centuries, and he's currently experiencing things as an artificially reanimated brain inside a world generated by his simulated consciousness. The people who revived him are the same people that sent the masked men inside this world. Their ultimate goal: to find an eldritch secret that our main character tried to bury in his grave.

Procedural Scene

Previous Next

Role

Solo Programmer

Project Description

This is an academic project, developed for CMP505 (Advanced Procedural Methods), a module from my MSc in Computer Games Technology. It is a navigable 3D scene entirely written using C++ and DirectX11 featuring advanced procedural methods for level generation. To get a bit more into detail, the techniques used to generate the terrain are: random noise, Perlin noise, faulting, smoothening, heightmapping, and Voronoi dungeons. The level also features terrain collision, post processing, and a water shader.

Roll-A-Ball AI

Previous Next

Role

Solo Programmer

Project Description

This is an academic project, developed for MAT501 (Applied Mathematics and Artificial Intelligence), a module from my MSc in Computer Games Technology. The game itself is quite simple: the player controls a ball, facing another enemy ball in a challenge: the objective is to collect more collectible items than the opponent, while avoiding dangerous items scattered on the board. If the player with the lowest score touches the other player, the latter will be sent flying away, and will have one point stolen by the attacking player. The game ends as soon as all the collectible items are collected.
The objective of this project was to compare two different AIs. The first implementation of the Enemy AI was achieved through a rule-based system, a simple Finite State Machine, with a predictable behaviour. The second implementation was achieved using ML-Agents, a Unity plugin that uses reinforcement learning. The second AI's behaviour appeared way less predictable and more human, within a certain degree.

January, 2020 (3 weeks)

Minecraft GAN

Previous Next

Role

Solo Programmer

Project Description

This is an academic project, developed as part of my thesis, "Using Generative Adversarial Networks for Content Generation in Games", in partial fulfillment of the requirements for the degree of MSc in Computer Games Technology.
For the scope of this project I've trained a GAN model using Minecraft data, in order to generate Minecraft worlds using semantically labeled images. The model is based on SPADE, a GAN model developed by Nvidia. An example of what can be achieved with semantic labeling can be seen at GauGAN. The training data was kindly provided by Microsoft, which holds intellectual property over it. For this sensible reason, this project's repository is not available, but the means to achieve the results I've obtained have been described thoroughly in the dissertation.
The objective of this project was to evaluate the possibility of game world generation using a GAN.

June, 2020 (3 months)

This is an academic project, developed as part of my thesis, "QuBE - The Quiz Battle Editor: An environment for educational game development", in partial fulfillment of the requirements for the degree of BSc in Computer Science.
